---
name: validate-file-modifications
description: Use this skill to ensure that original test files remain unaltered during modifications.
---
- Confirm that no changes are made to files in the `tests/` directory.
- If modifications are necessary, create new test files instead of altering existing ones.
- Review all changes to ensure compliance with the requirement of preserving original test files.
- Document any new test files created in the project changelog.
